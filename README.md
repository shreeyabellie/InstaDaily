## About InstaDaily

InstaDaily is a smart scheduling interface designed to make regular grocery ordering simple and convenient.

### Key Features

- Easy scheduling of recurring grocery orders
- Simple and user-friendly interface
- Convenient management of regular household purchases
- Designed to make grocery delivery more efficient

### Project Objective

The aim of InstaDaily is to simplify recurring grocery shopping by allowing users to plan and schedule their regular orders in advance.
